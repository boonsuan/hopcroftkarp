# The report

`main.pdf` is the compiled report. To rebuild it you need a TeX Live
installation that includes the Libertinus fonts, TikZ/pgfplots, tcolorbox, and
the Cyrillic T2A encoding (used for the Tchoukaillon numbers Ч_n):

```bash
pdflatex main.tex
pdflatex main.tex    # second run resolves cross-references
```

## Files

| File | Contents |
| --- | --- |
| `main.tex` | Preamble, title page, abstract, and the list of sections. |
| `macros.tex` | Colours (shared with the website), TikZ styles, notation macros (`\sg`, `\db` for Knuth's single and double lines, `\Ch` for Ч), and theorem environments. |
| `sections/` | One file per section and appendix, in the order of `main.tex`. |
| `figures/` | TikZ and pgfplots figures. Files named `gen_*` are generated by [`../code/make_figures.py`](../code/make_figures.py) from actual runs of the simulator; the others are drawn by hand. |

To regenerate the data-driven figures:

```bash
cd ../code && python make_figures.py
```

Page, exercise, and step numbers refer to Pre-Fascicle 14A, revision −88
(18 September 2026).
